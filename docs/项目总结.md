# API 智能客服系统 — 项目总结

> 日期：2026-05-26 | 版本：v4.0.0 | 路径：`/Users/onchain/wys/pytools/dspy/`

---

## 项目定位

基于 RAG（检索增强生成）+ mem0 记忆的多 Agent 智能客服系统。客户输入问题，系统自动检索 115 块技术文档并结合语义记忆生成详细回答。支持中文和英文提问。

---

## 技术栈

| 层级 | 技术 |
|------|------|
| 后端 | Python 3.9+ / FastAPI / Uvicorn |
| 前端 | 原生 HTML + CSS + Vanilla JS（无框架依赖） |
| LLM | OpenAI 兼容接口，支持 7 种提供商 |
| 向量检索 | ChromaDB + `paraphrase-multilingual-MiniLM-L12-v2` |
| 记忆系统 | mem0（fastembed 本地向量化） / simple_memory（备选） |
| 关键词检索 | TF-IDF + 中文停用词过滤 + 英文术语权重加倍 |
| 文档切块 | Markdown 按标题切分（≤1200字/块），超长二次段落切分 |

## 系统架构

### 整体流程

```
客户提问 → 意图分类 → 经验匹配 → 文档检索 → 多主题反问 → 质量校验 → AI 生成 → 经验沉淀
```

### 多 Agent 协同

```
server.py /api/ask
  ├─ classify_intent()       ← 主Agent（关键词规则，零延迟）
  │   ├─ greeting  → 硬编码问候
  │   ├─ unknown   → 硬编码拒答引导
  │   ├─ business  → biz_agent（占位）
  │   └─ knowledge → kb_agent（RAG+mem0+LLM）
  │
  └─ kb_agent.chat()
       ├─ search_docs()      ← TF-IDF + ChromaDB 向量检索
       ├─ mem_recall()       ← mem0 跨会话记忆
       ├─ 多主题检测          ← 跨主题先反问确认
       ├─ 预算控制            ← MAX_RAG_CHARS=3000
       └─ call_ai_api()      ← 7种AI提供商
```

### 四层协同

| 层次 | 职责 | 核心能力 |
|------|------|----------|
| 文档层 | 知识库管理 | 自动下载切块（115块）、文件上传、URL导入、搜索爬虫 |
| 检索层 | 精准匹配 | TF-IDF + ChromaDB 向量检索、中文停用词过滤、KYC硬规则提权、标题去重 |
| 回答层 | AI 生成 | 7种AI兼容、mem0记忆注入、上下文预算控制、多轮对话历史（6轮） |
| 学习层 | 经验积累 | 每日日志、模式提炼（67条）、mem0跨会话持久化、30天自动清理 |

## 功能清单

**问答能力**
- 自动检索 115 块文档并生成回答（Markdown 格式，含表格/代码块）
- 知识库外的问题直接礼貌拒答，不编造
- 多主题反问：模糊提问（如「KYC」）由 LLM 基于知识库 chunks 生成自然问句
- 上下文预算控制：无论文档多大，传入 LLM 最多 3000 字符
- 同一会话内支持 6 轮对话上下文关联
- 英文提问自适应语言检测

**多 Agent 意图分类**
- 5 种意图：greeting / unknown / business / knowledge
- 关键词规则匹配，不调 LLM，零延迟、100% 可控
- 主 Agent 路由 + 知识库 Agent（RAG+LLM）+ 业务 Agent（占位）

**知识库管理**
- 三种导入方式：上传文件、粘贴 URL（GitHub 自动适配）、搜索爬虫
- 来源可查、可删、可一键恢复默认
- 爬虫无需第三方 API Key

**mem0 记忆系统**
- 跨会话持久化用户画像和对话历史
- 语义搜索，自动提取关键信息
- fastembed 本地向量化，无需外部 API
- 备选方案：simple_memory（sentence-transformers）

**前端体验**
- 暗色主题界面，侧栏 + 聊天区布局
- Markdown 富文本渲染（表格斑马纹、代码块等宽字体、标题层级）
- AI 设置面板（7 种提供商 + 连接测试 + Key 脱敏）
- 文档管理面板（上传/URL/搜索 + 文件浏览/删除）
- 用户列表 + 记忆详情查看

**工程化**
- `src/` + `tests/` 标准目录结构
- 20 个 API 接口（核心 + 配置 + 文档管理 + 记忆查看）
- `.gitignore` 保护敏感配置（api_config.json / .env / chroma_db）

## 质量保障

五条防线保证回答不失控：

1. **意图分类** — greeting/unknown 直接短路返回，不浪费 AI 调用
2. **多主题反问** — 检索跨主题先反问确认，避免答非所问
3. **上下文预算** — 3000 字符硬上限，文档再大不撑爆 token
4. **生成约束** — 必须基于知识库，禁止编造
5. **来源可追溯** — 每条回答标注匹配度和引用文档
