## 项目定位

面向客户的 API 智能问答系统。客户输入问题，系统自动检索技术文档并生成详细回答。支持中文和英文提问。

---

## 系统架构

```
客户提问 → 经验匹配 → 文档检索 → 质量校验 → AI 生成回答 → 经验沉淀
```

四层协同：

| 层次 | 职责 | 核心能力 |
|------|------|----------|
| 文档层 | 知识库管理 | 自动下载切块（115 块）、文件上传、URL 导入、搜索爬虫 |
| 检索层 | 精准匹配 | TF-IDF 关键词检索、中文停用词过滤、KYC 智能提权 |
| 回答层 | AI 生成 | 7 种 AI 服务商兼容、知识库硬约束、多轮会话记忆 |
| 学习层 | 经验积累 | 每日日志、模式提炼、simple_memory 本地语义记忆、30 天自动清理 |

---

## 功能清单

**问答能力**
- 自动检索文档并生成中文回答
- 回答包含 API 地址、方法、完整参数表、错误码、示例
- 知识库外的问题直接礼貌拒答，不编造
- 模糊问题主动追问确认场景
- 同一会话内支持多轮对话上下文关联

**知识库管理**
- 三种导入方式：上传文件、粘贴链接（GitHub 自动适配）、智能搜索爬虫
- 来源可查、可删、可一键恢复默认
- 爬虫无需第三方 API Key，零成本运行

**自主学习**
- 每次对话自动记录日志
- 高质量回答提炼为经验模式
- simple_memory 本地语义记忆：跨会话保持用户画像和历史回答
- 旧日志 30 天自动清理

**前端体验**
- GitHub 风格暗色主题界面
- AI 回答支持富文本渲染（表格、代码块、标题层级）
- 8 个高频问题快捷入口
- AI 配置仅需三项参数

## 质量保障

四条防线保证回答不失控：

1. **检索校验** — 无关问题不浪费 AI 调用
2. **生成约束** — 必须基于知识库，禁止编造
3. **经验修正** — 历史经验持续优化回答
4. **来源可追溯** — 每条回答标注匹配度和引用文档
