# API 智能客服系统 — 项目总结

> 日期：2026-05-26 | 版本：v4.0.0 | 路径：`/Users/onchain/wys/pytools/dspy/`

---

## 项目定位

基于 RAG（检索增强生成）+ mem0 记忆的多 Agent 智能客服系统。客户输入问题，系统自动检索技术文档并结合语义记忆生成详细回答。支持中文和英文提问。

---

## 技术栈

| 层级 | 技术 |
|------|------|
| 后端 | Python 3.9+ / FastAPI / Uvicorn / httpx |
| 前端 | 原生 HTML + CSS + Vanilla JS（无框架依赖） |
| LLM | OpenAI 兼容接口，支持 7 种提供商 + reasoning 模型兼容 |
| 向量检索 | ChromaDB + `paraphrase-multilingual-MiniLM-L12-v2`（384维）+ TF-IDF 降级 |
| 分类索引 | chunk 加 `category` 字段（一级标题），ChromaDB `where` 过滤 + TF-IDF 预过滤 |
| 记忆系统 | mem0（fastembed 本地向量化） / simple_memory（备选） |
| 关键词检索 | TF-IDF + 中文停用词过滤 + 英文短术语权重加倍（KYC/API 等直接追加） |
| 文档切块 | Markdown 按标题切分（≤1200字/块），超长二次段落切分 |

## 系统架构

### 整体流程

```
客户提问 → 意图分类 → 短业务追问（≤5字） → 经验匹配 → 分类检索 → 多主题反问 → 质量校验 → AI 生成 → 经验沉淀
```

### 多 Agent 协同

```
server.py /api/ask
  ├─ classify_intent()       ← 主Agent（关键词规则，零延迟）
  │   ├─ greeting  → 硬编码问候
  │   ├─ unknown   → 硬编码拒答引导
  │   ├─ business  → kb_agent.chat()（P2-01：临时路由到知识库Agent）
  │   └─ knowledge → kb_agent.chat()（RAG+mem0+LLM）
  │
  └─ kb_agent.chat()
       ├─ 短业务追问          ← 充值/开卡/查余额/冻结/解冻（≤5字直接追问，不检索）
       ├─ search_docs()      ← 分类推断 → ChromaDB 语义检索 / TF-IDF 关键词降级
       │   ├─ 英文短术语增强  ← KYC/API 等 ≤4字母术语直接追加到搜索词
       │   ├─ KYC 硬规则提权  ← 强制插入核心接口块
       │   └─ 标题去重        ← 同标题只保留最高分
       ├─ 多主题检测          ← 一级主题 ≥2 个且非具体提问 → 反问确认
       ├─ 时间戳增强检索      ← HMAC毫秒 + 查询接口秒 同时检索合并
       ├─ mem_recall()       ← mem0 跨会话记忆
       ├─ 预算控制            ← MAX_RAG_CHARS=3000
       └─ call_ai_api()      ← 7种AI提供商 + reasoning 模型兼容（content空时取reasoning_content）
```

### 四层协同

| 层次 | 职责 | 核心能力 |
|------|------|----------|
| 文档层 | 知识库管理 | 自动下载切块、文件上传、URL导入（GitHub自动转raw）、搜索爬虫、category 分类字段 |
| 检索层 | 精准匹配 | ChromaDB 语义检索 + TF-IDF 关键词降级、category 预过滤、英文短术语权重加倍、KYC硬规则提权、标题去重、多主题检测 |
| 回答层 | AI 生成 | 7种AI兼容 + reasoning模型兼容、mem0记忆注入、上下文预算控制（3000字符）、多轮对话历史（6轮/12条）、语言自适应（中/英） |
| 学习层 | 经验积累 | 每日日志、模式提炼、mem0跨会话持久化、30天自动清理 |

## 功能清单

**问答能力**
- 自动检索文档并生成回答（Markdown 格式，含表格/代码块）
- 知识库外的问题直接礼貌拒答，不编造
- 短业务追问：充值/开卡/查余额/冻结/解冻等短词（≤5字）直接追问，不盲目检索
- 多主题反问：模糊提问（如「KYC」）由 LLM 基于知识库 chunks 生成自然问句
- 上下文预算控制：无论文档多大，传入 LLM 最多 3000 字符
- 同一会话内支持 6 轮对话上下文关联（session 隔离，12条消息上限）
- 英文提问自适应语言检测（system prompt + user message 双指令）
- 时间戳问题增强检索：同时检索 HMAC（毫秒）和查询接口（秒）两类文档

**多 Agent 意图分类**
- 4 种意图：greeting / unknown / business / knowledge
- 关键词规则匹配，不调 LLM，零延迟、100% 可控
- business 意图临时路由到知识库 Agent（P2-01：biz_agent 开发完成后切回）

**知识库管理**
- 三种导入方式：上传文件、粘贴 URL（GitHub 自动转 raw 链接）、搜索爬虫
- 来源可查、可删、可一键恢复默认
- 爬虫无需第三方 API Key
- 每个 chunk 自动提取 `category` 字段（一级标题），用于检索预过滤

**mem0 记忆系统**
- 跨会话持久化用户画像和对话历史
- 语义搜索，自动提取关键信息
- fastembed 本地向量化，无需外部 API
- 备选方案：simple_memory（sentence-transformers）

**前端体验**
- 暗色主题界面，侧栏 + 聊天区布局
- Markdown 富文本渲染（表格斑马纹、代码块等宽字体、标题层级）
- AI 设置面板（7 种提供商 + 连接测试 + Key 脱敏显示）
- 文档管理面板（上传/URL/搜索导入 + 来源浏览/删除/一键恢复默认）
- Vault 文件浏览（qa_logs / summaries / patterns 目录）
- 系统状态面板（health 接口实时展示文档块数、经验数、RAG状态）

**工程化**
- `src/` + `tests/` 标准目录结构
- 20 个 API 接口（核心问答 + 配置管理 + 文档管理 + 经验库 + Vault 浏览 + 健康检查）
- `.gitignore` 保护敏感配置（api_config.json / .env / chroma_db / docs_cache / memory_store.json）

## 质量保障

六条防线保证回答不失控：

1. **意图分类** — greeting/unknown 直接短路返回，不浪费 AI 调用
2. **短业务追问** — 充值/开卡等短词（≤5字）先追问确认意图，不盲目检索
3. **分类预过滤** — 按问题关键词推断 category，ChromaDB/Tf-IDF 先做分类过滤
4. **多主题反问** — 检索结果跨主题时先反问确认，避免答非所问
5. **上下文预算** — 3000 字符硬上限，文档再大不撑爆 token
6. **生成约束** — 必须基于知识库，禁止编造；无命中时明确告知"文档未提及"

## 项目结构

```
dspy/
├── server.py              # FastAPI 入口（20 个 API）
├── src/
│   ├── agent.py           # 检索协调 + 分类推断 + 多主题反问 + 关键词增强
│   ├── doc_loader.py      # 文档加载切块（含 category 字段）
│   ├── rag_store.py       # RAG 检索（ChromaDB 语义 + TF-IDF 降级 + category 过滤）
│   ├── mem0_manager.py    # mem0 记忆管理（fastembed 本地向量化）
│   ├── simple_memory.py   # 备选记忆（sentence-transformers）
│   ├── obsidian_writer.py # 日志/经验写入
│   ├── web_crawler.py     # 搜索爬虫
│   ├── dspy_rag_optimizer.py  # DSPy 优化模块（预留）
│   └── agents/
│       ├── kb_agent.py    # 知识库 Agent（短业务追问 + RAG + mem0 + LLM）
│       └── biz_agent.py   # 业务 Agent（占位）
├── static/index.html      # 前端单页应用
├── tests/                 # 回归测试
├── docs/                  # 项目文档（5 篇）
├── docs_cache/            # 知识库缓存（chunks.json + sources.json）
├── chroma_db/             # ChromaDB 向量库持久化目录
├── chroma_viewer.py       # ChromaDB 查看脚本（Python CLI）
├── api_config.json        # AI API 配置
├── memory_store.json      # 对话记忆数据
├── requirements.txt       # Python 依赖
└── .env                   # 环境变量（可选）
```
