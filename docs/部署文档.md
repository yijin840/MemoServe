## 系统概述

API 智能客服系统是一个基于 RAG（检索增强生成）技术的智能问答系统，专为 API 用户提供技术支持。

### 核心功能

- **智能问答**：基于知识库的准确技术问答
- **多轮对话**：支持上下文关联的多轮对话
- **记忆系统**：记住用户历史对话，提供连贯服务
- **多意图识别**：自动识别问候、知识查询、业务咨询等意图
- **Markdown 渲染**：支持表格、代码块等富文本展示

### 系统架构

```
┌─────────────┐
│                     用户层                           │
│           Web UI (HTML + JavaScript)                │
└──────────────────┬──────────────────────────────────┘
                   │ HTTP POST /api/ask
┌──────────────────▼──────────────────────────────────┐
│                  服务层                              │
│         FastAPI (server.py)                        │
│  - 意图识别 (classify_intent)                      │
│  - 路由到对应 Agent                                │
└──────────────────┬───────────────────────────────────┘
                   │
        ┌──────────┴──────────┐
        │                     │
┌───────▼────────┐    ┌───────▼────────┐
│  知识库 Agent   │    │  业务咨询 Agent  │
│  (kb_agent.py) │    │  (biz_agent.py) │
└───────┬────────┘    └──────────────────┘
        │
┌───────▼───────────────────────────────────┐
│              能力层                         │
│  - RAG 检索 (doc_loader.py)              │
│  - LLM 调用 (OpenAI 兼容 API)           │
│  - 记忆系统 (simple_memory.py)           │

        │
┌───────▼───────────────────────────────────┐
│              数据层                         │
│  - 知识库文档 (docs_cache/)               │
│  - 向量索引 (docs_cache/chunks.json)      │

## 快速部署

### 1. 克隆代码

```bash
git clone <repository-url> pytools/dspy/
cd pytools/dspy/
```

### 2. 安装依赖

```bash
pip3 install -r requirements.txt
```

**预计安装时间**：5-10 分钟（取决于网络速度）

**注意事项**：
- `sentence-transformers` 会下载约 400MB 的本地向量化模型
- 如果下载缓慢，可以配置国内镜像源

### 3. 配置 API

编辑 `api_config.json`：

```json
{
  "provider": "custom",
  "api_key": "YOUR_API_KEY=***
  "base_url": "https://your-api-endpoint.com",
  "model": "your-model-name",
  "temperature": 0.7,
  "max_tokens": 2048,
  "enabled": true
}
```

**配置项说明**：

| 字段 | 必填 | 说明 |
|------|------|------|
| provider | 是 | API 提供商类型，填 "custom" |
| api_key | 是 | 你的 API 密钥 |
| base_url | 是 | API 端点 URL（OpenAI 兼容格式） |
| model | 是 | 使用的模型名称 |
| temperature | 否 | 温度参数，默认 0.7 |
| max_tokens | 否 | 最大输出 token 数，默认 2048 |
| enabled | 否 | 是否启用 LLM，默认 true |

### 4. 准备知识库文档

将 API 文档（Markdown 格式）放到项目根目录或指定目录，然后运行：

```bash
python3 doc_loader.py
```

这会：
1. 扫描项目中的 `.md` 文件
2. 按标题层级切分成 chunk
3. 生成向量索引到 `docs_cache/chunks.json`
4. 记录文档元信息到 `docs_cache/sources.json`

**预计处理时间**：首次处理约 1-2 分钟

### 5. 启动服务

```bash
python3 server.py
```

**成功启动标志**：

```
INFO:     Started server process [PID]
INFO:     Waiting for application startup.
INFO:     Application startup complete.
INFO:     Uvicorn running on http://0.0.0.0:8000
```

### 6. 验证部署

```bash
curl -X POST http://localhost:8000/api/ask \
  -H "Content-Type: application/json" \
  -d '{"question":"你好","session_id":"test-001"}'
```

**预期响应**：

```json
{
  "answer": "你好！我是 API 技术支持助手...",
  "method": "greeting",
  "doc_hits": 0,
  "session_id": "test-001"
}
```

## 知识库管理

### 文档格式要求

- **格式**：Markdown (`.md`)
- **编码**：UTF-8
- **结构**：使用标准 Markdown 标题层级（`#`, `##`, `###`）

**示例**：

```markdown
# API 文档

## 认证方式

### HMAC-SHA256 认证

HMAC-SHA256 认证需要以下参数：
- api_key: 你的 API 密钥
- timestamp: 毫秒级 UNIX 时间戳
- sign: HMAC-SHA256 签名

#### 示例代码

```python
import hmac, hashlib, time
timestamp = int(time.time() * 1000)
sign = hmac.new(secret.encode(), f'{api_key}{timestamp}'.encode(), hashlib.sha256).hexdigest()
```
```

### 文档切分规则

`doc_loader.py` 按以下规则切分文档：

1. 按 `##` 或 `###` 标题切分成 chunk
2. 每个 chunk 最大 1200 字符
3. 超长 chunk 会二次切分（按 `\n\n` 段落分隔）
4. 每个 chunk 保留标题路径（如 `认证方式 > HMAC-SHA256 认证`）

### 重新构建索引

当知识库文档更新后，需要重新运行：

```bash
python3 doc_loader.py
```

这会：
- 重新扫描所有 `.md` 文件
- 重新切分 chunk
- 重新生成向量索引
- **覆盖**原有的 `docs_cache/chunks.json`

**注意事项**：
- 重建索引期间服务可以正常运行（使用旧的索引）
- 重建完成后**重启服务**以加载新索引

### 查看知识库状态

```bash
# 查看 chunk 数量
python3 -c "import json; d=json.load(open('docs_cache/chunks.json')); print(f'Total chunks: {len(d)}')"

# 查看文档来源
cat docs_cache/sources.json | python3 -m json.tool
```

## 服务启动

### 开发环境

```bash
cd /path/to/pytools/dspy/
python3 server.py
```

服务启动在 `http://localhost:8000`

### 生产环境（推荐）

使用 `systemd` 管理服务（Linux）或使用 `pm2`（跨平台）。

#### systemd 配置示例

创建 `/etc/systemd/system/mem0-demo.service`：

```ini
[Unit]
Description=PayCrypto Customer Service API
After=network.target

[Service]
Type=simple
User=www-data
WorkingDirectory=/opt/pytools/dspy/dspy/
ExecStart=/usr/bin/python3 /opt/pytools/dspy/dspy/dspy/server.py
Restart=always
RestartSec=10
StandardOutput=append:/var/log/mem0-demo.log
StandardError=append:/var/log/mem0-demo.error.log

[Install]
WantedBy=multi-user.target
```

启动服务：

```bash
sudo systemctl daemon-reload
sudo systemctl enable mem0-demo
sudo systemctl start mem0-demo
sudo systemctl status mem0-demo
```

#### 使用 pm2（推荐，跨平台）

```bash
# 安装 pm2
npm install -g pm2

# 启动服务
cd /path/to/pytools/dspy/
pm2 start server.py --name mem0-demo --interpreter python3

# 查看日志
pm2 logs mem0-demo

# 开机自启
pm2 startup
pm2 save
```

### 部署步骤

#### 1. 安装依赖

```bash
# 创建虚拟环境（推荐）
python3 -m venv venv
source venv/bin/activate

# 安装依赖
pip install -r requirements.txt
```

#### 2. 配置反向代理（Nginx）

编辑 `/etc/nginx/sites-available/mem0-demo`：

```nginx
server {
    listen 80;
    server_name cs-api.yourdomain.com;

    # 重定向到 HTTPS
    return 301 https://$server_name$request_uri;
}

server {
    listen 443 ssl http2;
    server_name cs-api.yourdomain.com;

    ssl_certificate /path/to/cert.pem;
    ssl_certificate_key /path/to/key.pem;

    location / {
        proxy_pass http://127.0.0.1:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;

        # WebSocket 支持（如果前端需要）
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
    }
}
```

启用配置：

```bash
sudo ln -s /etc/nginx/sites-available/mem0-demo /etc/nginx/sites-enabled/
sudo nginx -t
sudo systemctl reload nginx
```

#### 3. 使用多进程启动

```bash
# 使用 uvicorn 多进程模式
uvicorn server:app --host 0.0.0.0 --port 8000 --workers 4
```

**workers 数量建议**：
- CPU 核心数 × 2 + 1
- 例如：4 核 CPU → 9 workers

#### 4. 配置防火墙

```bash
# 只开放 80 和 443 端口
sudo ufw allow 80/tcp
sudo ufw allow 443/tcp
sudo ufw enable
```

### 安全建议

1. **API Key 保护**：
   - 不要将 `api_config.json` 提交到 Git
   - 使用环境变量或密钥管理服务

2. **CORS 配置**：
   - 在 `server.py` 中配置允许的域名：

   ```python
   from fastapi.middleware.cors import CORSMiddleware
   app.add_middleware(
       CORSMiddleware,
       allow_origins=["https://yourdomain.com"],
       allow_credentials=True,
       allow_methods=["*"],
       allow_headers=["*"],
   )
   ```

3. **Rate Limiting**：
   - 使用 Nginx 限制请求频率：

   ```nginx
   limit_req_zone $binary_remote_addr zone=cs_zone:10m rate=10r/s;
   location / {
       limit_req zone=cs_zone burst=20 nodelay;
       proxy_pass http://127.0.0.1:8000;
   }
   ```

4. **日志轮转**：
   - 使用 `logrotate` 管理日志文件

## API 接口文档

### POST /api/ask

**描述**：向客服系统提问

**请求参数**：

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| question | string | 是 | 用户问题 |
| session_id | string | 否 | 会话 ID，用于多轮对话 |
| stream | boolean | 否 | 是否流式返回（预留） |

**请求示例**：

```json

  "question": "KYC认证需要哪些材料？",

}
```

| 参数 | 类型 | 说明 |
|------|------|------|
| answer | string | AI 回答内容 |

| doc_hits | int | 命中的知识库文档数量 |
| session_id | string | 会话 ID |
| error | string | 错误信息（失败时） |

```json
{
  "answer": "KYC认证需要以下材料：\n1. 身份证正面照片\n2. 身份证反面照片\n3. 护照信息页（可选）\n\n请通过 POST /api/v1/customers/accounts 接口提交。",

  "session_id": "user-123"

```json
{
  "answer": "抱歉，暂时无法回答您的问题，请联系技术支持。",
  "method": "unknown",
  "doc_hits": 0,
  "session_id": "user-123",

## 故障排查

### 常见问题

#### 1. 服务无法启动

**症状**：`Address already in use`

**排查**：

```bash
# 查看端口占用
lsof -i :8000
# 或
netstat -tulpn | grep 8000

# 杀死占用进程
kill -9 <PID>
```

#### 2. LLM API 调用失败

**症状**：返回答案为空或报错

**排查**：

```bash
# 测试 API 连通性
curl -X POST "https://api.deepseek.com/v1/chat/completions" \
  -H "Authorization: Bearer YOUR_API_KEY=***
  -H "Content-Type: application/json" \
  -d '{"model":"deepseek-chat","messages":[{"role":"user","content":"hello"}]}'
```

**可能原因**：
- API Key 错误
- base_url 配置错误
- 网络不通（防火墙/代理问题）
- API 配额用完

#### 3. 知识库检索结果不准确

**症状**：相关问题返回无关内容

**排查**：

1. 检查文档是否被正确切分：

```bash
python3 -c "import json; d=json.load(open('docs_cache/chunks.json')); print(d[0])"
```

2. 调整 `doc_loader.py` 中的 `max_chars` 参数（默认 1200）
3. 优化文档结构（增加标题层级、关键词）

#### 4. 记忆系统不工作

**症状**：多轮对话无法记住上下文

**排查**：

```bash
# 查看记忆文件是否存在
ls -la memory_store.json

# 查看记忆内容
cat memory_store.json | python3 -m json.tool | head -50
```

**可能原因**：
- `simple_memory.py` 未被正确导入
- `sentence-transformers` 模型未下载完整
- 磁盘空间不足

#### 5. 响应速度慢

**症状**：API 响应时间 > 5 秒

**排查**：

1. 检查 LLM API 响应速度（可能是 API 服务端问题）
2. 检查 `sentence-transformers` 是否在用 CPU 推理（可以考虑用 GPU）
3. 减少 `doc_loader.py` 中的 `top_k` 参数（默认 10）

### 日志分析

**关键日志位置**：

| 日志 | 位置 | 说明 |
|------|------|------|
| 服务日志 | `server.log` 或通过 systemd/pm2 查看 | 记录每次 API 调用 |
| 文档加载日志 | 运行 `doc_loader.py` 时的输出 | 记录文档切分过程 |
| 回归测试日志 | `/tmp/regression_result.json` | 记录测试结果 |

**常见错误日志解读**：

```
ERROR: API 调用失败: Connection timeout
```
→ 网络问题或 LLM API 服务不可用

```
WARNING: RAG 检索结果分数过低: 2.5
```
→ 用户问题可能与知识库内容不匹配，属于正常情况

```
ERROR: sentence_transformers 模型加载失败
```
→ 模型文件损坏或未完整下载，删除 `~/.cache/torch` 重新下载
