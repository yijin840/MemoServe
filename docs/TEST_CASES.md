## TC-06 · 后续对话带出记忆（个性化响应）

**用户问题**：我们TechPay Ltd遇到的API 401问题，认证方式应该怎么配置？

**客服实际回答**（摘要）：
> 根据您此前提供的机构名称 **TechPay Ltd** 和当前问题（API 401 认证错误），结合知识库内容，以下是标准认证配置说明：
>
> ## ✅ 正确的 API 认证方式（适用于 TechPay Ltd）
>
> API 使用 **HMAC-SHA256 签名认证**，需在请求头中提供以下字段：
>
> | 请求头字段 | 说明 |
> |-----------|------|
> | `X-App-Key` | 机构 App Key |
> | `X-Timestamp` | 请求时间戳 |
> | `X-Signature` | HMAC-SHA256 签名 |
>
> 签名计算方式：`sign = HMAC-SHA256(secret, app_key + timestamp + body)`
>
> ⚠️ 常见 401 原因：
> - 服务器时间与标准时间偏差超过 ±5 分钟
> - Secret 配置错误
> - IP 未加入白名单

**测试要点**：
- ✅ **记忆成功召回**：回答中出现了"TechPay Ltd"和"401 认证错误"等上下文
- ✅ 回答高度个性化，非泛泛而谈
